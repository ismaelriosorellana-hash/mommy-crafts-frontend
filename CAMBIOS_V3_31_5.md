# Mommy Crafts Frontend V3.31.5 — estabilización Etapa 0A

## Cambios

- Se unifica `CONFIG.APP_VERSION` en 3.31.5.
- Todos los recursos CSS y JavaScript publicados utilizan `?v=3.31.5` para evitar mezclas de caché.
- Se conservan las mejoras del encabezado incluidas hasta la versión 3.31.4.
- Se eliminan copias de parches, aplicadores y versiones antiguas del sitio que no deben publicarse.
- Se amplía `.gitignore` para excluir respaldos, cachés y archivos temporales.
- Se incorpora `.gitattributes` para evitar cambios falsos por saltos de línea entre Windows y Linux.

## No modifica

- Diseño público.
- Configuración visual guardada.
- Catálogo.
- Carrito.
- Checkout.
- Cuenta de cliente.
- Mercado Pago.
