# Mommy Crafts Frontend 3.33.0 — Etapa 2A

## Ficha de producto de alto impacto

- Título del producto más grande y con jerarquía visual dominante.
- Tamaño responsive reforzado en móvil.
- Resumen breve visible junto al título.
- Marca y SKU visibles cuando están disponibles.
- SKU actualizado al seleccionar una variante.
- Estado de reseñas honesto: no se muestran estrellas completas cuando no existen reseñas.
- Precio dentro de un bloque visual destacado.
- Ahorro monetario visible cuando existe precio anterior.
- Disponibilidad presentada como indicador claro.
- Enlace directo a las opciones de entrega.
- Botón de compra más visible y área de acciones mejor organizada.
- Bloque de confianza con pago protegido, personalización, cambios y contacto.
- Mejor adaptación del área de compra en pantallas móviles.

## Compatibilidad

- Backend requerido: 2.14.1 o superior.
- No requiere nuevas variables de entorno.
- No requiere cambios en MongoDB Atlas.
